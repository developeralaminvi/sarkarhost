# Sarkar Host - Modern Agency & IT Solutions WordPress Theme

**Sarkar Host** is a custom, high-performance, responsive WordPress theme designed for IT companies, web hosting providers, digital marketing agencies, SEO consultants, and software firms.

---

## 🚀 Key Features

- ⚡ **Ultra-fast & Lightweight**: Built with clean PHP, vanilla JavaScript, and modern CSS (No heavy framework dependencies).
- 📨 **Leads & Inquiries Management System**:
  - Automatically captures inquiries from service modals, custom contact forms, and Contact Form 7.
  - Direct 1-click **WhatsApp Chat** (`wa.me`) and **Direct Call** (`tel:`) buttons in WP Admin.
  - Lead status management (`New`, `Contacted`, `Confirmed`) and CSV data export.
- 🛡️ **Anti-Spam & Real-time Validation**:
  - Bangladesh mobile number format check (`013, 014, 015, 016, 017, 018, 019` - 11 digits).
  - Real-time inline feedback & shake animation on invalid input.
  - Spam link & URL blocker.
  - Honeypot bot protection.
- 📧 **Admin HTML Email Notifications**: Sends responsive email notifications with instant WhatsApp reply & call buttons when any form is submitted.
- 📱 **Mobile-First Responsive Design**: Sleek slide-in mobile drawer with accordion sub-menus and backdrop blur effects.
- 🌟 **Dynamic Active Menu Indicator**: Glowing lime underline indicator for the current page and parent service dropdown.
- ⚙️ **Smart Theme Settings Control Panel**: Manage branding colors, office addresses, phone numbers, WhatsApp, map links, and view all 12 shortcodes with 1-click copy.

## 🛠️ Installation

1. Upload the `sarkarhost` folder to your `/wp-content/themes/` directory.
2. Activate the theme via **WordPress Admin > Appearance > Themes**.
3. Go to **Sarkar Host Settings** in the WordPress Admin sidebar to customize office details, contact numbers, and brand colors.
