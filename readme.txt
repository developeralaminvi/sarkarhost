== Description ==
A modern, dark-tech aesthetic WordPress Theme inspired by Aleric IT Consulting. Built specifically for Sarkar Host IT, SEO, Web Development, Hosting, and Marketing Services.

== Key Features ==
* 100% Mobile Responsive & Fast Loading
* Global Theme Settings Page (Contact Info, Office Locations, Colors)
* Contact Form 7 integration support
* Modular Shortcodes for every section and page
* Dynamic Header & Footer Menu Locations
* Ready-to-use Page Templates for Homepage, SEO, Web Dev, Hosting, Marketing, Graphics, and Contact
